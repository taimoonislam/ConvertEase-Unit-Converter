# ConvertEase — Smart Unit Converter

ConvertEase is a modern, responsive unit conversion web application designed to make everyday conversions simple, fast, and convenient. It features a clean interface, multiple conversion categories, language options, and useful tools for managing conversion results.

## ✨ Features

- **Multiple Conversion Categories:** Length, Weight, Temperature, Area, Volume, Speed, Time, and Data Storage.
- **Instant Conversion:** Calculate results quickly by entering a value and selecting units.
- **Temperature Conversion:** Supports Celsius, Fahrenheit, and Kelvin conversions.
- **Unit Swapping:** Quickly switch the source and target units.
- **Quick Presets:** Access common conversion examples.
- **Conversion History:** Review recent conversions.
- **Favorites:** Save frequently used conversions for quick access.
- **Copy Result:** Copy conversion results to the clipboard.
- **Light and Dark Themes:** Switch between display themes.
- **Multilingual Interface:** Supports English, Bangla, and Banglish.
- **Responsive Design:** Designed to work across desktop, tablet, and mobile screens.
- **Local Storage:** Saves supported preferences, history, and favorites in the browser.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the `ConvertEase` folder in Visual Studio Code.
3. Make sure `index.html`, `style.css`, and `script.js` are in the same folder.
4. Open `index.html` using the Live Server extension, or open it directly in your browser.
5. Select a conversion category, enter a value, and choose the units.
6. Explore the history, favorites, language, and theme options.
